# ESP32-Elite 演示项目

[English](README.md)

ESP32-Elite 开发板的演示项目集合

ESP32-Elite 是一款基于 LCKFB ESP32S3 核心的开发板，
专为初学者设计，用于探索 ESP32 平台的功能。

以下是安装模块后的开发板图片：
![ESP32-Elite Board](imgs/asm.png)

以下是拆除模块后的开发板图片：
![ESP32-Elite Board without modules](imgs/no_mods.png)

这些演示项目设计用于 VSCode 中的 PlatformIO 扩展，
让用户可以轻松地将代码上传到开发板并与其交互。

## 快速开始

0. 在 VSCode 中安装 PlatformIO 扩展
1. 在 VSCode 中打开其中一个演示项目
2. 将代码上传到你的 ESP32-Elite 开发板
3. 看看会发生什么！

## 可用演示

- **演示 0**: Hello World
  - 一个简单的演示，用于闪烁板载 LED，
    向串口监视器打印计数值，
    并回显从串口监视器接收的消息。

- **演示 1**: 按钮和 LED
  - 演示如何使用按钮控制 ESP32-Elite 开发板上的 LED，
  并在按下按钮时向串口监视器打印消息。

- **演示 2**: ADC
  - 演示如何从电位器读取模拟值，
  将其显示在串口监视器上，
  并创建一个任务根据电位器位置
  控制 LED 闪烁频率。

- **演示 3**: RGB
  - 演示如何使用 `Adafruit_NeoPixel` 库
  控制 WS2812 RGB LED，
  并通过中断检测的按钮按下来改变其颜色。

- **演示 4**: IMU
  - 演示如何使用板载 IMU（惯性测量单元）
  LSM6DS3 读取加速度和陀螺仪数据，
  并将数值打印到串口监视器或使用 VSCode 中的
  `Teleplot` 扩展可视化姿态。

- **演示 5**: 音频
  - 演示如何使用 `Audio` 库从 SPIFFS
  文件系统播放音频文件，
  并使用开发板上的按钮控制播放。

- **演示 6**: 矩阵
  - 演示如何使用 `U8G2` 库控制 8x8 LED 矩阵，
  显示滚动文本消息。

- **演示 7**: 麦克风
  - 演示如何使用板载数字麦克风捕获音频数据，
  根据麦克风检测到的音量控制 LED 数量，
  并将音量打印到串口监视器，
  可以使用 VSCode 中的 `Teleplot` 扩展进行可视化。

- **演示 8**: LCD 简单显示
  - 演示如何使用板载 LCD 显示模块显示简单文本消息，
  并使用开发板上的按钮控制显示。

- **演示 9**: LVGL-LED-ADC
  - 演示如何使用 LVGL 库创建简单的 GUI，
  显示电位器的当前值，
  并允许通过按钮输入使用复选框控制 LED。

- **演示 10**: LVGL-频谱图
  - 演示如何使用 LVGL 库创建简单的音频频谱分析器，
  以图形格式显示从板载麦克风捕获的音频级别。
